# Atlas géographique de l’Algérie

Carte interactive du relief, de l’hydrographie, des limites administratives et de la toponymie de l’Algérie.

Site : https://merabah.github.io/atlas-geographique-algerie/

## Lancer en local

```bash
python3 server.py
```

Puis ouvrir http://127.0.0.1:8765

Le serveur lit les fichiers dans `public/`. Les mêmes fichiers sont aussi à la racine du dépôt pour GitHub Pages.

## Données

Données ouvertes pour le prototype : SRTM / tuiles de terrain, cours d’eau OpenStreetMap, limites administratives.

INCT et ANRH restent les références nationales.
